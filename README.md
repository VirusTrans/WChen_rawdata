## **Raw data and analysis scripts**

### Spatial evolutionary landscapes in avian hosts facilitate the emergence of H9N2 variants with human-adaptive traits

#### This repository contains the raw data and analysis scripts used to process, analyze, and visualize H9 sequences and next-generation sequencing data from our H9N2 virus study. Each folder includes the raw data along with the scripts used for data processing and figure generation.
